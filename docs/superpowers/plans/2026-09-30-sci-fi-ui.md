# UI sci-fi (issue #3) — piano di implementazione

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** tema HUD olografico su tutta l'app, dock di controlli in basso, nuovo dettaglio stella con indicatori, overlay (anello B6 + finestrella) sulla stella selezionata.

**Architecture:** token Tailwind v4 in `@theme` + componenti React propri in `app/src/ui/hud/`. Logica pura (scale degli indicatori, lato della finestrella) in `app/src/lib/`, testata con Vitest (ambiente `node`, niente DOM). Stato condiviso (pannello del dock, overlay aperto) nello store zustand esistente. La proiezione dell'overlay segue il pattern di `StarLabels`: componente r3f che scrive `transform` su un nodo DOM, nessuno stato React per frame.

**Tech Stack:** React 19, TypeScript strict, Tailwind 4.3, zustand 5, @react-three/fiber 9, i18next, Vitest 4, Playwright 1.60 + axe.

**Spec:** `docs/superpowers/specs/2026-09-30-sci-fi-ui-design.md`

## Global Constraints

- Nessuna dipendenza nuova; versioni pinnate invariate (AGENTS §6).
- Nessun valore inventato: dato assente/non finito → `t('panel.na')` e `Gauge` senza marcatore (AGENTS §5).
- Palette esatta: accento `#9ec8ff`, valori/titoli `#d6e8ff`, etichette `#8aa0c0`, testo `#f4f8ff`, stime/avvisi `#ff9f5f`, fondo `rgb(10 16 30 / 0.82)`.
- Font di sistema: `--font-hud: 'Segoe UI', system-ui, sans-serif`; `--font-hud-mono: Consolas, 'Cascadia Mono', ui-monospace, monospace`.
- Ogni stringa nuova in `en/it/es/fr/de.json` (il test `tests/unit/i18n.test.ts` verifica la parità delle chiavi).
- Ogni animazione solo sotto `motion-safe:`; con reduced-motion niente rotazione, aggancio, sfarfallio.
- I `data-testid` esistenti restano (stessi nomi, stessi elementi).
- `axe` senza violazioni serious/critical su Galaxy e System View; contrasto testo ≥ 4,5:1.
- Mai array tipizzati grandi in state/props (vedi `starCoreStore`).
- Un branch + una PR per fase (F1–F4), come da spec §5. Branch base: `feat/sci-fi-ui`.

## Review Focus

1. **Valori `NaN`/non finiti nei dati** (`colorIndex`, `luminosity` ecc. usano `NaN` come "assente"): scale e `StatTile` devono trattarli come `null` → test in Task 3.1.
2. **Riselezione della stessa stella dopo la x**: `selectStar(i)` con `i` già selezionato deve riaprire l'overlay → test in Task 4.1.

5. **Pannello del dock aperto quando si entra nella System View** (es. Filtri, che lì non esiste): va chiuso → test in Task 2.1.
